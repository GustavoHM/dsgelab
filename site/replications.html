O que conta como replicação

A mesma equação, a mesma calibração, confrontadas com um número publicado ou com uma solução fechada. O bloco é executado por tools/check_site_examples.py.

Os exemplos de ensino do Dynare (Collard, Pfeifer) ficam na tabela de validação da página do pacote. São arquivos de manual, e a comparação lá é contra a solução do Dynare, variável a variável.

Heutel (2012), Review of Economic Dynamics

Garth Heutel, How should environmental policy respond to business cycles? Optimal policy under persistent productivity shocks, Review of Economic Dynamics 15, 244–264, 10.1016/j.red.2011.05.002. O porte está em dsgekit.examples.heutel e em docs/heutel.md. O sistema resolvido é o linear do código MATLAB do autor. Anderson–Moore entra como o Klein/QZ do pacote. O modelo não linear, que daria segunda ordem e previsão perfeita, não está neste exemplo.

Tabela 2 e o impulso de 1%

A Tabela 2, p. 251, traz α = 0,36, β = 0,98267, δ = 0,025, ρ = 0,95, σε = 0,007, η = 0,9979, θ₁ = 0,05607, θ₂ = 2,8 e 1 − γ = 0,696. A prosa da p. 250 imprime β = 0,98627. O exemplo segue a tabela e os scripts. A seção 4.1 simula uma inovação de 1% e descreve o consumo no máximo por volta do período 15. O capital, na mesma frase, fica «around period 40 (year 6)». Num modelo trimestral o sexto ano é o horizonte 24. A série resolvida atinge o máximo do capital no horizonte 25 e o do consumo no 15. O 40 não é o que este sistema produz, e o exemplo não desloca a série para coincidir com ele.

import numpy as np
from dsgekit.examples import heutel

p = heutel.Params()
assert p.alpha == 0.36 and p.beta == 0.98267 and p.delta == 0.025
assert p.rho == 0.95 and p.sd == 0.007 and p.eta == 0.9979
assert p.theta1 == 0.05607 and p.theta2 == 2.8
assert abs((1 - p.gamma) - 0.696) < 1e-12

ss = heutel.steady_levels("tax", p)
assert abs(ss["lambda"]) < 1e-10          # multiplicador de Ramsey no estado estacionário
assert 0 < ss["mu"] < 1 and ss["c"] > 0 and ss["e"] > 0

sol = heutel.solve("tax", p)
irf = sol.irf("eps_a", size=0.01, periods=100, percent=False)
assert np.max(np.abs(irf["a"] - 0.01 * p.rho ** np.arange(100))) < 1e-12
gap = ss["c"]*irf["c"] + ss["i"]*irf["i"] + ss["z"]*irf["z"] - ss["y"]*irf["y"]
assert np.max(np.abs(gap)) < 1e-10        # recursos ao longo do impulso
assert int(np.argmax(irf["c"])) == 15
assert int(np.argmax(irf["k"])) == 25
print(ss["k"], ss["y"], ss["mu"], int(np.argmax(irf["k"])))

Informação defasada, p. 262

Com o governo escolhendo o instrumento antes de ver o estado, o artigo substitui a condição de primeira ordem por τt = d · yt−1 e qt = d · yt−1. O d que ele publica é 1,415 para o imposto e 0,658 para a quota. Os scripts trazem 1,4151 e 0,6580. No período do choque o produto defasado ainda está no estado estacionário, e o instrumento não se move.

tax = heutel.Params.source("tax_asym")
quota = heutel.Params.source("quota_asym")
assert round(tax.policy_slope, 3) == 1.415
assert round(quota.policy_slope, 3) == 0.658

irf_tax = heutel.solve("tax_asym", tax).irf("eps_a", size=0.01, periods=100, percent=False)
assert abs(irf_tax["tau"][0]) < 1e-10
assert np.max(np.abs(irf_tax["tau"][1:] - tax.policy_slope * irf_tax["y"][:-1])) < 1e-10

irf_q = heutel.solve("quota_asym", quota).irf("eps_a", size=0.01, periods=100, percent=False)
assert abs(irf_q["q"][0]) < 1e-10
assert np.max(np.abs(irf_q["q"][1:] - quota.policy_slope * irf_q["y"][:-1])) < 1e-10
assert np.max(np.abs(irf_q["e"] - irf_q["q"])) < 1e-10
print(tax.policy_slope, quota.policy_slope)

A calibração literal do planejador nos scripts, θ₂ = 0,1 e γ = 0,8, é a sensibilidade da p. 258, e não produz estado estacionário admissível. heutel.solve("planner") levanta SteadyStateError. O caso-base da Tabela 2 pede heutel.solve("planner", heutel.Params()).

Crescimento estocástico com solução fechada

Brock e Mirman (1972, Journal of Economic Theory) colocam o crescimento ótimo sob incerteza. Com utilidade logarítmica e depreciação total a regra de um setor é exata, k′ = αβ a kα, e a solução log-linear é P = [[α, 1], [0, ρ]], F = [α, 1]. A versão com vários setores, a mesma utilidade e a mesma depreciação, é Long e Plosser (1983, Journal of Political Economy). O exemplo é o caso de um setor.

No processo log a′ = ρ log a + ε, a correção de risco de segunda ordem sobre a tecnologia é σ². É o termo de Jensen que a aproximação de Schmitt-Grohé e Uribe (2004, Journal of Economic Dynamics and Control) tem de devolver. O capital obedece à regra exata estado a estado, e a correção dele é zero. As tabelas numéricas daquele artigo são outro modelo.

import numpy as np
import dsgekit as dk
from dsgekit.examples import rbc

model, params, guess = rbc.build()
sol = dk.solve(model, params, guess=guess)
exact = rbc.closed_form(params)
assert np.allclose(sol.P, exact["P"]) and np.allclose(sol.F, exact["F"])

sigma = 0.007
so = dk.solve_second_order(sol, cov={"eps_a": sigma})
i_a = model.states.index("a")
i_k = model.states.index("k")
assert abs(so.h_ss[i_a] - sigma ** 2) < 1e-8
assert abs(so.h_ss[i_k]) < 1e-8
print(sol.P, so.h_ss[i_a])

Princípio de Taylor

Clarida, Galí e Gertler (2000, Quarterly Journal of Economics 115, 147–180): na regra i = φπ π + φx x, o equilíbrio determinado pede φπ > 1. O exemplo é o modelo de três equações com φπ = 1,5, φx = 0,125 e β = 0,99. O equilíbrio com esses coeficientes é determinado. Com φπ = 0,8 o mesmo sistema é recusado. Com φx positivo a fronteira exata deste modelo fica um pouco abaixo de 1; 0,8 está do lado indeterminado. O que se confere é esse limiar, não uma tabela de coeficientes estimados.

from dataclasses import replace
import dsgekit as dk
from dsgekit.examples import nk

model, params, guess = nk.build()
assert params.phi_pi == 1.5 and params.phi_x == 0.125 and params.beta == 0.99
sol_nk = dk.solve(model, params, guess=guess)
assert sol_nk.klein.n_stable == model.n_states

below = replace(params, phi_pi=0.8)
try:
    dk.solve(model, below, guess=guess)
    raised = False
except dk.BlanchardKahnError:
    raised = True
assert raised
print(sol_nk.klein.n_stable, raised)
